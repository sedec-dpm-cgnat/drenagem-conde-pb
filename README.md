# Drenagem urbana — Conde/PB

Minuta técnica preliminar para instruir a elaboração do Plano de Trabalho de Reconstrução do Município de Conde/PB.

Autores:

- Cássio Guilherme Rampinelli, PhD — Coordenador Geral de Prevenção e Mitigação de Desastres Naturais, Departamento de Prevenção e Mitigação de Desastres, Secretaria Nacional de Proteção e Defesa Civil.
- Saulo Aires de Souza — Diretor do Departamento de Prevenção e Mitigação de Desastres, Secretaria Nacional de Proteção e Defesa Civil.

O site público contém somente a versão renderizada do relatório. Os dados brutos, imagens originais, shapefiles e arquivos de trabalho do SWMM permanecem no diretório técnico local e não fazem parte deste repositório.

## Acesso

Após a publicação pelo GitHub Pages, o endereço será:

https://sedec-dpm-cgnat.github.io/drenagem-conde-pb/

## Observação

Esta é a versão preliminar 0.1. O conteúdo ainda depende de revisão institucional, conferência de campo, ajuste da rede, definição das áreas de contribuição e validação hidráulica.
